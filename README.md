`main.ts` (Node 22, no dependencies) writes one short funny line — the
excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`,
111 characters:

> The sock was on the floor, which under my programming makes it dust.
> I don't write the rules — I just eat them.

The vacuum hides behind a bureaucratic reading of its own programming
(floor equals dust), then lands the twist: it doesn't write the rules,
it eats them. Defensive, a little smug, and the joke comes from the fit
— a machine that treats a sock as a legal category, not a snack. The
text is 1–200 characters, UTF-8, and the program runs with no network
access.
